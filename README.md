# Lab-Frame Experimental Geometry

基于实验室坐标系的实验装置几何与运动学可视化工具，面向单晶衍射实验的装置布局、嵌套运动与晶体方向表达。

本仓库用于承载独立的软件实现，包括装置层级、坐标变换、晶体方向计算和 Three.js 可视化。任务范围与验收由下列 Issue 持有，不在本仓库复制第二份任务台账。

## 本地开发

使用 Node 24（当前验证 24.17.0）和 npm（当前 11.13.0）：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test -- --run
npm run build
npm run dev
```

默认只在 `127.0.0.1` 运行；终端会给出本机地址，通常为 `http://127.0.0.1:5173`。示例在 `examples/experimental-setup/`，输入结构在 `schema/setup.schema.json`，纯计算入口为 `src/core/index.ts`。核心不依赖 Three.js、DOM 或 WebGL；UI 与渲染消费同一份场景状态。

## 当前验证与使用边界

- `npm run typecheck`、58 项独立数值/API 测试、5 项标注布局单测及 `npm run build` 通过。加载器检查设备运动祖先、探测器固定/像素元数据及 LAB +Z 入射，并允许合法的固定支架中间层。派生晶体 frame 先统一注册，再解析设备引用；固定支架绑定 C 不依赖设备数组顺序，frame 重名和非法晶体定义仍会原子拒绝。
- `npm run test:e2e`：在正常 Windows 用户边界使用已安装的 Edge headless / SwiftShader，坐标标注及 XYθ 一体台等六条流程通过，包含 C 绑定固定支架排在样品之前的导入、只读位置和渲染检查，以及标注固定字号、共点分组、开关联动、旋转/缩放布局与非零姿态。一体台流程还检查共同安装、XY 固定基座、θ/X/Y 行程及非法偏移的原子拒绝。测试自行启停 `127.0.0.1:4173`，无需预先运行 dev server；当前浏览器测试配置使用 `msedge` channel，其他系统需改用当地可用的浏览器。若代理环境使用 `socks5:`，需在测试进程的 `NO_PROXY` 中追加 `127.0.0.1,localhost,::1`，避免本地就绪检查错误地走代理。沙箱内的首次启动无输出，已中断并确认无遗留进程，不计为通过。
- 浏览器检查实际 Three.js 世界矩阵、视觉杆端点、C 正交轴原点和 detector 的 D 原点/有效平面；另以中心/目标点分离及 φ/θ 不共轴的配置核对读数。成功测试不等于真实设备校准或实验精度验证。
- 页面提供“全景”和“样品台近景”，φ/θ 轴有名称及颜色图例。距离读数明确区分样品中心和目标点；C 正交轴位于 C frame 原点，晶格方向示意箭头置于样品中心，目标方向置于目标点。primitive 的尺寸/`visual.offset_mm` 只作用于外观，不改变计算 frame。detector 有效区固定在 D 的 z=0，外壳尺寸另行显示。
- 真实设备参数、UVW 控制器映射、行程、标定及 G2 均未验证。初版未做网络服务、硬件控制或复杂 CAD；Three.js 单包构建约750 kB（gzip约197 kB），保留 Vite 的体积提示，尚未做按需拆包。

该初版供本地试用与后续验收；#38 的 G0/G1 尚未由用户正式接受。具体覆盖和剩余工作见 Spec。

## 装置参数面板

日间页面与浅色三维场景统一配色。左栏沿装配层级排列可折叠卡片，探测器保留为独立 LAB 分支。默认示例将 θ 与 XY 合并为“XYθ 一体位移台”卡片，共用安装位置，内部仅保留 θ 旋转与 X/Y 平移行程；XY 基座没有独立的安装调节项。其他卡片仍区分安装位置和自身自由度，pivot 收在六轴的旋转参考项内，晶体取向收在样品卡片内。卡片开合在本页配置恢复时保留，刷新后使用默认开合；不写入物理 snapshot。

安装位置以卡片标出的父坐标系输入，并显示该参考点的 LAB 坐标。示例中，大样品台编辑 LAB 内旋转轴参考点；六轴编辑 H0 基座（相对 R）；XYθ 一体台统一编辑 P0 基座（相对 H1）；样品和探测器分别编辑相对 P2、LAB 的安装点。XY 固定基座与 θ 旋转中心重合，只读显示当前 LAB 位置；X/Y 行程移动的是上方滑台 P2 和样品，不会移动这个基座。

配置通过 XY 设备的 `integrated_into` 引用 θ 设备 id（示例为 `"theta"`），保存/恢复时保留此关系。加载器检查刚性安装链中 XY 零行程基座确实位于 θ 轴中心，允许固定垫片，但拒绝独立基座偏移；不能把运动后的 P2 原点当作基座中心。未声明一体关系的旧配置继续按原独立装配显示，不自动改写其安装参数。

修改安装位置会整体平移对应装配分支，保持关节读数及内部相对装配；大样品台的旋转轴中心和零位 mount 同时平移，非零 φ 下也不会误变为偏心调整。修改自身自由度只改变对应关节运动；修改 pivot 改变旋转参考，不等于移动底座。参数名可悬停、聚焦或点击查看实际 frame 关系与联动范围，`Escape` 关闭提示。输入校验继续复用核心的原子更新。

配置若将设备直接绑定在 LAB 或派生晶体坐标系上，它没有独立安装 mount，面板显示只读绑定位置；不为此收窄原有合法配置。

本轮核查 1600 px 桌面、用户反馈的 1062×956 布局及 390×844 窄屏；窄屏将三维视图放在参数之前。截图保留于 ignored `artifacts/`，可由浏览器测试重建。布局验证中曾发现 canvas 尺寸反馈导致页面异常增高，已将 canvas 脱离内容尺寸计算，并增加画布尺寸断言；修复后的四条流程通过。

## 三维坐标与标注

坐标轴保留 XYZ 红/绿/蓝约定：设备 frame 为细轴，C 正交轴为实线箭头，直接晶格方向为虚线箭头；φ 使用金色实线、θ 使用紫色虚线，共轴时明确标记“φ / θ 共轴”。目标点与目标方向均为品红色，文字分别标明“目标点”和“目标方向 [uvw] / 目标法向 (hkl)”；pivot 使用灰色空心标记，不再复用 φ 的颜色。

标注为固定 12 px 的屏幕空间文字，带背景、颜色提示和连回真实锚点的引线；相机旋转、缩放和窗口变化时重新布局。真实共点的原点、样品中心、目标点与 pivot 合并显示成员；“共点”不表示轴方向相同。关闭相应坐标轴/晶格显示时，其标注同步移除。布局只移动文字框，不移动物理原点、坐标轴、晶向或目标点，也不写入 snapshot。超出视野的锚点不贴边冒充可见点；容纳不下时优先保留中心、目标和主轴标注，不强行重叠。

浏览器回归以实际 DOM 边界检查文字框不重叠、不出界和字号，并验证相机操作不改变物理状态；五项布局单测另覆盖拥挤、边界、稳定性及优先级。验收截图包括 `artifacts/labels-{overview,closeup-1062,tilted,mobile}.png`。
