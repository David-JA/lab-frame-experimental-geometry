# Lab-Frame Experimental Geometry

基于实验室坐标系的实验装置几何与运动学可视化工具，面向单晶衍射实验的装置布局、嵌套运动与晶体方向表达。

本仓库用于承载独立的软件实现，包括装置层级、坐标变换、晶体方向计算和 Three.js 可视化。任务范围与验收由下列 Issue 持有，不在本仓库复制第二份任务台账。

## 本地开发

使用 Node 24（当前验证 24.17.0）和 npm（当前 11.13.0）：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test -- --run
npm run build
npm run dev
```

默认只在 `127.0.0.1` 运行；终端会给出本机地址，通常为 `http://127.0.0.1:5173`。示例在 `examples/experimental-setup/`，输入结构在 `schema/setup.schema.json`，纯计算入口为 `src/core/index.ts`。核心不依赖 Three.js、DOM 或 WebGL；UI 与渲染消费同一份场景状态。

## 装置参数面板

工作台默认近景、日间配色。左侧是约 270 px 的装置树和当前设备的单个检查器，探测器作为独立 LAB 分支；运动输入优先，安装与几何默认折叠。默认选中“XYθ 一体位移台”，共用安装位置，保留 θ 旋转及 X/Y 内部行程，XY 基座没有独立安装调节。pivot 在六轴旋转参考项内，晶体取向在样品检查器内。点击树或可见三维实体切换当前设备，XY 子实体归到 θ 宿主；刷新后使用默认选择。选择、相机和诊断总开关不写入 snapshot；诊断内原有的三个 `display` 开关仍随 snapshot 保存。

视口下方常驻带轴误差、目标点到 φ 轴、样品中心到 θ 轴三项读数；reciprocal 模式不冒称 direct 带轴误差。“配置”打开 JSON 导入/导出、比较与恢复，“读数详情”打开详细数值/诊断；恢复示例位于配置内，与相机的“全景/样品近景”操作分开。合成/未标定身份始终独立显示。

安装位置以卡片标出的父坐标系输入，并显示该参考点的 LAB 坐标。示例中，大样品台编辑 LAB 内旋转轴参考点；六轴编辑 H0 基座（相对 R）；XYθ 一体台统一编辑 P0 基座（相对 H1）；样品和探测器分别编辑相对 P2、LAB 的安装点。XY 固定基座与 θ 旋转中心重合，只读显示当前 LAB 位置；X/Y 行程移动的是上方滑台 P2 和样品，不会移动这个基座。

配置通过 XY 设备的 `integrated_into` 引用 θ 设备 id（示例为 `"theta"`），保存/恢复时保留此关系。加载器检查刚性安装链中 XY 零行程基座确实位于 θ 轴中心，允许固定垫片，但拒绝独立基座偏移；不能把运动后的 P2 原点当作基座中心。未声明一体关系的旧配置继续按原独立装配显示，不自动改写其安装参数。

修改安装位置会整体平移对应装配分支，保持关节读数及内部相对装配；大样品台的旋转轴中心和零位 mount 同时平移，非零 φ 下也不会误变为偏心调整。修改自身自由度只改变对应关节运动；修改 pivot 改变旋转参考，不等于移动底座。当前参数区底部常驻“装置说明”，随选择切换，集中说明运动约定、联动范围与安装坐标；参数名为普通标签，不再用重复浮窗。pivot、XY 内部行程与 R_SC/索引的专属说明紧贴对应参数块。输入校验继续复用核心的原子更新。

配置若将设备直接绑定在 LAB 或派生晶体坐标系上，它没有独立安装 mount，面板显示只读绑定位置；不为此收窄原有合法配置。

本轮核查 1600 px 桌面、1062×956 和 390×844；窄屏视口位于参数之前，向下编辑参数时仍保留观察区域。`artifacts/workbench-{1062,overview,mobile}.png` 由 E2E 刷新；`artifacts/final-picking-{xy,hexapod,phi}.png` 与 `final-reciprocal-mobile.png` 记录最终边线、实体选择和窄屏法向检查。截图在 ignored `artifacts/`，不另存源码版本。

## 三维坐标与标注

坐标轴保留 XYZ 红/绿/蓝约定：设备 frame 为细轴，C 正交轴为实线箭头，直接晶格方向为虚线箭头；φ 使用金色实线、θ 使用紫色虚线，共轴时明确标记“φ / θ 共轴”。目标点与目标方向均为品红色，文字分别标明“目标点”和“目标方向 [uvw] / 目标法向 (hkl)”；pivot 使用灰色空心标记，不再复用 φ 的颜色。

标注为固定 12 px 的屏幕空间文字；普通方向/轴名轻量显示，当前选择及共点提示适当强调，并有颜色提示与真实锚点引线。常规模式只保留任务相关标注；“坐标诊断”启用设备 frame、C 正交轴和晶格的独立显示选项。仅真实点与 frame 原点执行共点归组，短提示可打开成员及各轴 LAB 方向；示意箭头尖端/轴名锚点即使世界坐标重合也分别避让，不能因为任意绘图长度形成共点详情。共点不表示同向。布局不移动物理几何，也不写入 snapshot。超出视野的锚点不贴边冒充可见点；关键目标标签另有显式可见性断言。

28 项展示/布局测试覆盖真实共点、方向端点偶合、投影重叠、避让、边界、优先级、展示策略、取景、实际矩阵、拾取与跨帧布局稳定性；浏览器回归检查 DOM 边界、关键标签可见、字号和相机操作不改物理状态。标签保留上一帧仍合法的锚点相对位置（含亚像素），不因左右等距时的像素取整而反复换边；遇越界或碰撞仍重新避让。该偏移只在渲染层使用，不进入 snapshot。`center_s_mm=[-30,0,0]` 时 C X 和 [100] 的示意端点重合仍独立显示，正常原点共点详情也保留。截图包括 `artifacts/labels-*.png`、`final-direction-overlap.png` 和 `device-description-hexapod.png`。中文显式使用 Microsoft YaHei / Noto Sans CJK SC，已核查最终导出。
