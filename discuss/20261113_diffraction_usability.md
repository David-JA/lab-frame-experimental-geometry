## 复现与设计

用户报告 `Nonfinite pixel quadrature result` 和较小 ROI 也提示超限。已在默认实验室/理想对中两场景复现：σ_g 从0.001改为0.01 Å⁻¹时，整帧200万次求积评估耗尽。`adaptive()` 此时用 Infinity 表示未知误差，后来被误报为“非有限数值”；这是计算预算不足，不能据此判断三维强度密度出了 NaN。ROI 超限比较的是整帧剩余预算，并非单斑可用的固定20万像素。

新增交互预览的自适应分组：仍将同一个三维密度在 Ewald 球面上积分，但把相邻原始像素的并集作为一个积分区域。按反射支持面积及潜在激发数选择2的整数次幂分组尺度；没有逐帧归一化、没有另铺二维高斯，也不丢弃 HKL。`tile.stride` 表示组边长，板边最后一组按实际有限板面裁切。显示时按组/预览格面积交叠分配组总量，保留总信号，但组内空间细节不再解析。

UI 默认自动分组，可选逐原始像素。计算 API 默认仍逐原始像素，只有显式 `adaptiveBinning` 或 `pixelStride` 才生成分组结果；保存的 UI 采样偏好不会自行改变 `computeForwardFrames` 的原始像素默认合同。分组输出明确标记 `sampling_stride`，UI 的 `raw_sum` 为null，另给 `integrated_sum`，避免被下游误当作原始像素图。原始像素模式及未完成状态继续保留。

## 行为与参数

- 正常宽斑预览通过分组降低计算量；耗尽预算时仍报未完成，但区分评估次数、ROI剩余预算、递归精度与真正非有限值，给出切换自动模式、缩窄或减小枚举范围的操作。
- 斑宽按钮按0.8/1.25倍调整。Gaussian推荐σ_g=0.001 Å⁻¹；均匀球推荐D=4√ln2×0.001≈0.00333 Å⁻¹，替代旧圆斑示意D=0.1作为积分模式的复位初值。旧圆斑模式与旧配置的D仍保留。
- 近似峰宽匹配按钮在Gaussian与均匀球之间换形：D=4√ln2 σ_g。明确这是局部平面下的rocking FWHM匹配，不是实测角宽，也不把两形状归一化到相同峰高。超出球直径输入范围时拒绝匹配，不静默声称匹配成功。
- 灰度上限/显示阈值按固定512²预览格的相对信号解释。一次适配亮度以当前帧的预映射峰值设置上限，之后各帧仍共用该上限；没有信号或积分未完成时拒绝适配并保留旧标尺。显示阈值不删除计算信号。
- 能量1–500 keV、球直径10⁻⁶–0.2 Å⁻¹、HKL上限1–12沿用模拟器范围；Gaussian宽度/晶格常数须为正，极小宽度仍受浮点角分辨率限制。这些是模型/软件输入范围，不是硬件安全限位。样品/光束尺寸只影响照明与重心，不直接预测真实计数。

局部验证重点：完整/板边的每组值应等于相同raw网格上的严格像素和；非整除板尺寸不得发明板外像素。缩图守恒、A1–A3严格模式、旧配置/复位、一般宽度与姿态的自动模式、参数按钮及亮度固定均需核查。已归档验收数据保持原版本，不覆盖为此处的新输出。
