## 目标与授权边界

从中心强、边缘弱的各向同性三维高斯倒易反射斑出发，在每个指定的固定曝光姿态用 Ewald 球面截取强度，并按实际探测器像素边界积分。该帧总信号与信号的空间分配必须来自同一积分，保留跨帧相对大小。新增归一化均匀球作为斑形对照，保留现有圆斑示意和 HKL 查询。

初始授权是创建 Spec 和 Astra high review，交付为可供后续实施的设计；本文中的算法、验收阈值和任务均为计划，不代表实现或科学验收已经完成。2026-11-13 用户追加授权为本 Spec 和 README 入口创建分支、提交、推送和 PR，并在建 PR 后由 Astra 评审 PR 正文；A 的实现、PWA 仿真、云端 Issue 更新及发布仍不在本轮范围。后续 A 的实施依据本 Spec；历史首版合同继续保留在[归档 Spec](../docs/archive/20261111_diffraction_preview_spec.md)。本轮用户指令覆盖 #3 [旧说明](https://github.com/David-JA/lab-frame-experimental-geometry/issues/3#issuecomment-6794866278)中以独立二维核分配既有响应作为 A 主路径的建议。

模型输出为理想相对信号，不是不同 HKL 的真实强弱或绝对计数。B 的结构因子、材料/仪器强度预测与输入盘点均不进入本次交付。曝光期间连续旋转积分、有限源体积展宽、发散度、能谱、吸收、探测器 PSF/效率、噪声、背景、饱和及实际提峰也不进入 A 首版。固定姿态各帧采用相同的单位曝光因子。

## 设计动机与证据身份

用户提供的 #173 算例固定同一取向、130 个带符号候选 HKL、1.00 m 近板，以 120° 为中心的 ±45° 窗口，基础步长 0.20°，比较相同额外帧数的原窗口半步加密与旋转 180° 后的对侧窗口。两种斑形匹配到 0.10° 的中位 rocking FWHM，门槛为每个反射自身峰值的 10%。

## 前向模型合同

### 1. 单位、反射总量与宽度

沿用 `g=1/d`，晶格长度 Å、倒易坐标 Å⁻¹、装置长度 mm、UI 角度 °。令 `k=1/λ`、`ki=(0,0,k)`，`B=A⁻ᵀ`。姿态 ψ 下的中心为 `g_h(ψ)=R_LAB,S(ψ) R_SC B h`，h 是带符号 HKL 列向量；ψ 只是扫描姿态标签，实际旋转由 Scene 定义，不把所有机械轴硬编码为 Y 轴。

对每个反射定义非负有限的总相对散射强度 `W_h`，默认所有允许反射均为 1。它表示三维倒易密度积分 `∫ρ_h(q;ψ)d³q=W_h`，不等于某帧信号，也不意味着真实 HKL 等强。高级数值入口允许按带符号 HKL 提供人为指定的 W；未覆盖项取 1，重复项拒绝。UI 首版无需建设材料强度编辑器。

各向同性高斯：

```text
ρ_h(q;ψ) = W_h / ((2π)^(3/2) σ_g³)
           × exp(−|q−g_h(ψ)|² / (2σ_g²))
```

`σ_g>0` 的单位为 Å⁻¹，是三个正交倒易坐标共同的标准差；一维剖面 FWHM 为 `2√(2ln2)σ_g`。这不是 rocking 角 FWHM，也不是旧直径。

均匀球对照：

```text
ρ_h(q;ψ) = 3W_h/(4πR_g³),  |q−g_h(ψ)| < R_g
           0,             其余位置
R_g = D_g/2
```

采用上述严格开球约定；一般交圆边界的取值不影响面积积分，但 `c=0、R_g=k` 的重合球面例外，按开球返回零，不能当作完整球帽。比较宽度/斑形时保持 W 相同；不得把不同宽度都归一化到同一个峰高。三维总量相同仍可产生不同峰高和 rocking 曲线。旧 `weight=max(0,1−(Sg/R_g)²)` 是中心截面峰高归一化的局部平面近似，仅用于 legacy，不是此处球对照的总信号。

与 #173 交换时明确 `Q=2πg`、`σ_Q=2πσ_g`、`R_Q=2πR_g`；若交换密度本身，应有 `ρ_Q(Q)=ρ_g(Q/(2π))/(2π)³`，保留三维总量 W。只传宽度时也必须写明 convention，禁止仅标 Å⁻¹。

### 2. 同一次 Ewald 截取决定帧总量和像素分布

弹性出射单位方向 s 对应 `q(s)=k s−ki`，满足 `|q+ki|=k`。本模型采用倒易空间的**球面面积测度** `dS_g=k²dΩ`，不混用体积、单位立体角密度或任意平面切片。定义固定全局因子 `g_ref=1 Å⁻¹`：

```text
J_h(ψ) = g_ref ∫_{Ewald 全球面} ρ_h(q;ψ) dS_g
```

该因子使 J 与 W 均可标作相对单位，不包含通量、曝光、结构因子或探测器响应。它在所有帧、HKL、距离和斑形间保持相同；将来若用 Q-space 球面积分，固定因子也须按 `Q_ref=2πg_ref` 转换，才能与此定义一致。W 固定时改变 σ_g 会改变单帧 J；不能以逐帧归一化抵消这一变化。曲线展示可另附 `J/max(J)` 以比较峰翼，但必须同时保存原始 J 和统一标尺图。

对 detector 像素 (i,j)，从当前受照重心 S 发射。像素内的连续 raw 坐标为 `(u,v)`，点位与方向如下：

```text
P(u,v) = C + x_D px [u−(Nu−1)/2] + y_D py [(Nv−1)/2−v]
r = P−S;  s = r/|r|;  q = k s−ki
I_h[i,j] = g_ref ∫_{u=i−1/2}^{i+1/2} ∫_{v=j−1/2}^{j+1/2}
           ρ_h(q;ψ) k² |n_D·s| px py / |r|² dv du
```

`px,py,|r|` 同用 mm；`px py |n_D·s|/|r|²` 是像素物理面积到立体角的 Jacobian。像素索引 `i=0..Nu−1`、`j=0..Nv−1`，外缘半开，与 `projectRay` 一致。只积真正沿前向射线能到达当前板面的方向；平行或反向不接收，板面穿过源点的奇异几何须报告无法计算。像素化必须保留倾角、非方像素、偏心源和距离因素。

`I_frame[i,j]=Σ_h I_h[i,j]` 在线性域累加，显示映射随后进行。不能先算旧 W(ψ) 再任选二维核；也不添加独立的二维 Gaussian blur。若将来用局部近似加速，必须与此精确几何合同对照并满足同一误差门。

### 3. 独立全球面积分基准

像素和仅覆盖板内方向，一般小于全球面 J。对于球对称密度，令 `c=|ki+g_h|`，可独立用一维积分得到：

```text
J_h/g_ref = 2πk² ∫_{−1}^{1} ρ_h(sqrt(k²+c²−2kc t)) dt
```

其中 `ρ_h(r)` 表示距反射中心 r 的径向密度。该基准不调用生产像素积分器、ROI 分配或显示代码。高斯可另用解析式交叉核对（`c>0`）：

```text
J_h/g_ref = W_h k/(√(2π) σ_g c)
            × exp(−(c−k)²/(2σ_g²)) × (1−exp(−2kc/σ_g²))
```

`c=0` 直接取 `4πk²ρ_h(k)`，避免除零；高斯解析式使用稳定的指数差计算。均匀球在 `c>0、|c−k|<R_g<c+k` 时交球帽面积为 `πk[R_g²−(c−k)²]/c`，乘其常密度即可；无交集为零，`c>0、R_g≥c+k` 时面积为 `4πk²`（等号只排除一个零面积点）。`c=0` 时仅 `k<R_g` 接收全部 Ewald 球面，`k≥R_g` 为零；开球在 `R_g=k` 的直接取值不同于 `c→0⁺` 的极限。生产路径仍按像素边界积分，不把解析总量回填或重归一化像素和。

### 4. 积分误差、尾部与面板裁切

用反射附近 ROI/稀疏 tile 积分可接受，最终数值仍位于原始 Nu×Nv 像素网格；不得先算 512² 图后插值冒充原始积分。高斯计算支持采用 `|q−g_h|≤mσ_g`，m 及尾部预算写入结果；截断后的密度不重新归一化。ROI 必须包住该支持能照到板面的全部像素，包括中心在板外但支持入板的情况。

不能仅凭三维高斯尾概率断言某个离峰帧的球面积分误差很小。对指定姿态用同一球面测度评估支持外尾量（可复用独立径向积分），或用扩大 m 的收敛对照与可说明的上界；记录遗漏相对固定 `J_scale` 的大小。A1–A3 审计用 `J_scale=J_ref_peak`，即该反射在声明扫描支内独立求得的峰值。UI 或无扫描支的单姿态调用用 `J_scale=J_h(c=k)`，由前述解析式按当前 k、宽度、W 直接计算，是假想反射中心落在 Ewald 球面上的固定参照响应；它不随本帧偏离量变化、不暗中执行角扫。两种尺度均仅用于误差度量，不归一化输出，并在结果中注明选择。计算尾截断、像素求积误差、有限板损失、显示阈值四者单独报告。

像素求积采用可细化的确定性规则，对均匀球的支持边界做细分或解析边界处理；禁止只取像素中心值或仅用子格都未命中便认定窄斑为零。通过几何支持求交定位窄斑，无法在预算内解析时返回 `unresolved`/未达到精度，不以空图冒充零信号。达到误差门后再返回可验收结果。

首版验收规划值如下，均为模型数值精度目标，非实验准确度。令 `B_h=10⁻⁶ J_scale`。代表帧满足 `|I_sum−J_board_ref| ≤ 10⁻³ J_board_ref+B_h`；球面尾截断上界不超过 B_h；球面基准自身的解析/独立数值差不超过 `10⁻⁸ J_scale`。其中 `J_board_ref` 为独立按实际板面方向范围计算的信号，不含显示阈值。需报告像素求积细化前后的差异；完整落板样例的板外量也不超过 B_h。“完整”对无限高斯是这个数值含义，不是严格紧支撑。W=0 的贡献直接返回零；整条扫描支没有信号时，审计使用样例中声明的非零共同峰值尺度作绝对门，不作除零相对误差。

仅检查整板总量不能保证信号被分配到正确像素。A2 还须将独立球面裁切 oracle 的接受边界设为选定 raw 像素的四条边，对非对称 2×2/3×3 邻域各像素输出 `I_pixel_ref`，核对 `|I_pixel−I_pixel_ref| ≤ 10⁻³ I_pixel_ref+10⁻⁸ J_scale`。选定像素 oracle 的细化差及估计误差预算分别不超过 `10⁻⁹ J_scale`；记录独立求积规则和边界定位精度，不能通过读取生产图或调用生产像素积分函数得到参照。原始像素方向/下标必须一并核对，防止左右/上下互换仍通过总量检验。

独立板内/逐像素 oracle 是验收审计工具，不要求 UI 每帧重复执行。实时路径必须记录自身求积细化和尾预算是否达到，并给出解析全球 J；没有运行独立审计的 `J_board_ref`、`I_pixel_ref` 及参照保留比例返回 null，不能冒称独立验证通过。实时可另报 `received_fraction_estimate=I_sum/J` 并注明其数值误差。若解析 J=0（包括 W=0、均匀球支持外帧），板内量、板外量与像素贡献均为 0，所有以 J 为分母的比例为 null；若 J>0 而板内失收，则保留比例为 0，两种状态明确区分。

## 配置、图像和界面

计划新增可选 `diffraction.intensity_model` 对象，`kind='gaussian_3d'|'uniform_sphere_3d'`；高斯保存显式 `sigma_g_invA`，均匀球使用原 `spot_diameter_invA` 作 D_g。`reflection_model` 继续只指 FCC/primitive，不混作斑形开关。W 默认 1；需交换指定强度时在同一模型对象中按带符号 HKL 保存覆盖项。要求宽度有限且 >0、W 有限且 ≥0；违反这些条件、未知 kind、重复 HKL 及其他非法配置经 Schema/语义校验拒绝，restore 失败保持旧状态。

缺少 `intensity_model` 的旧配置仍使用旧圆斑示意，缺项往返仍保持缺项，不能静默升级为精确均匀球。UI 提供“圆斑示意（旧）/三维高斯/三维均匀球（积分）”三个明确入口；新建场景可显式选高斯并使用 `σ_g=0.001 Å⁻¹` 的 synthetic 初值。这个值不是从旧 D=0.1 套得，也未按实测 rocking 宽度标定；切到高斯时不改写旧 D。切回 legacy 保留原参数，保存/载入/复位/采用四月参照须有确定且可见的行为：预览复位恢复当前模式的演示宽度及 W=1，保留装置/标定/取向；采用四月参照保留模式、宽度与 W 等人为选择。

数值入口接收完整 Scene snapshot、模型参数和指定姿态列表，每帧固化实际变换与 source，返回原始线性像素图（Float64 或等价精度的稀疏 tiles）、每反射贡献/像素和、J 全球面、接收比例估计及误差状态；审计模式补独立板内/指定像素参考值和参照保留比例，未计算的参照字段及零分母比例为 null。每个 tile 声明 raw 原点、宽高、行优先顺序，未存像素为零；只有满足尾预算时方可省略。不同单反射输出合成时必须共享像素网格和姿态，不按各自 ROI 数组下标直接相加。

无需为了 #173 建通用批处理服务或真实 TIFF 管线；一个可调用的无 DOM 入口和代表样例的数值交付足够。结果元数据保留单位、g/Q convention、W、宽度、m、像素网格、姿态、发射点、几何、算法版本、误差门与真实达到状态；显示阈值和灰度参数另存。

UI 可采用 512²/1024² 预览，但下采样应把原始线性像素按面积/格子交叠求和，缩放前后保留总量，标出预览格与原始像素区别。选择整个对比序列共用的固定线性灰度上限（可由用户整体调整并记录），不得逐帧自动拉伸；若增加 log 映射，必须标明并同时保留线性原图。显示阈值不修改原始数组、不影响计算支持或 HKL 检出定义。HKL、点击区、最小标记和直射束十字作为独立叠层，不向图像加信号；局部重叠仍可查询各反射。

保持默认收起、关闭停算、手动修改立即更新和运动约每秒采样；每帧是固定姿态单位曝光，不声称累计两次刷新间的运动。计算未结束时标记当前计算姿态/revision，不能把旧图标为新姿态。UI 性能可先测代表参数的耗时/内存，再在相同误差合同内使用 ROI、缓存或可取消计算；预算不足须可见，不静默降低精度。桌面与 390 px 窄屏须可操作且 HKL 可读。中文图/截图显式采用 Microsoft YaHei 或 Noto Sans CJK SC，并检查字形、负号、数学符号。

## 三组可复算验收

以下都是后续实现必须生成的结果，不是本次文档创建已经执行的计算。样例共用可保存 snapshot，列出晶胞、HKL、波长、Scene 变换、原始板面/像素、source、W 与积分控制量。参数包必须能从仓库独立重建，不依赖私有 PWA 数据或当前浏览器状态。

### A1：单 HKL 扫过 Bragg

选 `(200)` 及同一固定、完整受照 source，以已存在的居中 synthetic 场景/四月参照几何构造一条孤立 Bragg 扫描支。冻结其余参数，对均匀球与高斯分别求独立全球面 J(ψ)；在同一支上数值求峰值和左右半高交点，调整宽度使两者 rocking FWHM 匹配到 0.10°（差≤0.5%）。局部平面下 `FWHM_Sg,sphere≈√2 R_g`、`FWHM_Sg,gaussian≈2√(2ln2)σ_g` 只用于初值；不得由此宣称角宽已精确匹配，也不要求每个 HKL 都有同一角宽。

扫描覆盖峰值和两侧至少到 `J/J_peak<0.01`（均匀球也包含支持外的零帧）；细步长最多为目标 FWHM 的 1/20，并通过半步加密验证峰宽。分别交付峰中心、两侧半高附近、两侧约 10% 峰翼以及支持外代表帧的原始像素和统一灰度图；包括一个峰位于采样两帧之间的序列，保留峰位置与采样相位。

绘制随 ψ 的原始像素和、独立 J、板内参考信号与误差，另附按各自峰值缩放的曲线说明匹配峰宽后的峰翼差异。完整落板下像素和与 J 在上述误差门内吻合；原始像素和不能被强行调成相同峰高。不得要求复现动机表的 61/60→63/66 或把 10% 阈值装进生产积分器。

### A2：亚像素与板边

固定同一个反射、姿态、σ_g/R_g、W、source 及面板朝向/法向距离，仅在板面内平移探测器，改变落点亚像素相位，例如 `(0,0)、(0.25,0.25)、(0.5,0)、(0.5,0.5)、(0.75,0.25)` px。分别对高斯和均匀球执行，并至少包含 σ 对应投影宽度小于一个像素的样例；完整落板时 J 恒定，原始像素间重新分配，总和在误差门内保持。还须加入 `(0.2,0.35)` 等不具上下/左右对称性的相位，对窄高斯及跨像素边界的均匀球，按前述逐像素误差门与独立 oracle 核对选定邻域全部像素；至少一个采用倾斜板或非方像素的样例，以约束方向和 Jacobian。交付 raw 下标、各像素参照、实算值与误差，不只看缩略图。

沿同一板内方向继续平移，覆盖斑点靠近板边、中心恰在边界、中心已越界但尾部/支持仍入板及完全失收。J>0 时报告 `f_board=J_board_ref/J`，并始终报告像素实收与 `J−J_board_ref`，不把裁切后的信号归一化回 1；J=0 时比例为 null，单列支持外/W=0 状态。对高斯“完全失收”仅指低于声明绝对误差预算。独立板内 oracle 使用与生产像素规则不同的球面方向/射线板面裁切积分，不从生产图的像素和反算 f；选定像素参照复用此 oracle，仅将接受范围换为该像素的四边。另用过对称中心的半平面参考（另一边界足够远）核查约 1/2 的保留比例，声明曲率/几何是否满足该对称条件。

### A3：两个局部重叠反射

使用同一冻结几何与姿态上的两个明确带符号 HKL；选择可重叠的宽度/取向，记录实际参数，不临时移动像素核凑重叠。必要时可用标明 synthetic 的倒易中心测试输入隔离线性算子，但至少一个验收样例必须从真实晶胞+整数 HKL+共同旋转生成。

用同一网格独立算出 I₁、I₂、两反射一起输入的 I₁₂，要求逐像素 `I₁₂=I₁+I₂`，双精度累加残差不超过 `10⁻¹²×max(1,|I₁|+|I₂|)` 相对单位；自适应积分的分块/求积选择须保持单反射可复用，避免按合成峰值改阈值导致不一致。交付映射前数组、差值最大位置/残差、三张统一标尺图。重叠时可查询两个 HKL；不做 dedup 或声称实际提峰会保留两个峰。
