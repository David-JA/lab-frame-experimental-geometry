默认入口为 `lab_height_config()`；`example_config()` 保留原合成基线，可通过 `?example=synthetic` 或配置抽屉恢复。两者共用加载、校验与完整 snapshot 格式，不维护第二套计算引擎。

## 坐标和状态约定

- LAB 为右手系，`+Y` 向上、`+Z` 为入射方向；设备长度用 mm，角度输入用 deg，晶格长度用 Å，方向输出为无量纲单位向量。
- 变换使用列向量，公开矩阵数组按行存储。完整数学定义与接口合同见 Spec，不以 Three.js 对象位置作为物理真值。
- 默认链为 `LAB → R → H0 → H1 → Z0 → Z1 → P0 → P1(θ) → P2(XY) → S → C`；探测器和光束独立属于 LAB。晶体 C 是正交坐标系，晶格基矢一般不正交。
- 六轴安装零位、关节平移/倾转和旋转参考点分别定义。内部 H0/H1 与厂图原点不能直接等同；参考面区别见尺寸记录，不据图纸标记推断控制器坐标或真实 pivot。
- `direct` 表示晶向，`reciprocal` 表示晶面法向；切换类型是重新解释指标，不是二者之间的换算。

## 编辑与兼容性

Scene 是唯一物理状态来源。编辑先构造候选 snapshot，再通过 `restore_state()` 校验并原子应用；失败不改变已有状态。输入结构由 Schema 约束，跨引用、层级和角色关系由加载器校验。

安装位置与内部运动分开处理：修改安装位置平移对应分支，保持内部关节读数；外层旋转轴中心与零位 mount 同步移动。默认大样品台的“台面升高”和安装 Y 共用更新路径，联动安装、轴心及柱体外观以保持柱底；“柱体外观高度”只改变外形并保持柱顶，不是升降运动。

XY 一体关系由 `integrated_into` 声明。加载器检查 XY 零行程基座位于 θ 轴中心，不把运动后的 XY 原点误当固定基座；未声明一体关系的旧配置仍按独立装配处理。直接绑定 LAB 或派生晶体坐标系的对象没有独立 mount，参数区保留只读绑定信息。

样品“观察方向”与“晶体取向”分别提交，各自从当前 Scene 保留另一组已应用值，不读取另一组未应用草稿。取向用单位四元数表示旋转 `R_SC`，修改它不移动样品机械位置。普通文件载入读取独立的文件内容缓存；高级 JSON 编辑读取自身草稿，不能互相替代来源。

snapshot 保存设备、装配、关节、样品和原有三个 display 开关。相机、当前选择、诊断总开关和查看预设只影响画面，不写入 snapshot。

## 外观与观察层

`visual.size_mm`、`visual.offset_mm` 只改变外观，不缩放物理 frame。六轴上下复合件分别附着 H1/H0；上盘可用 `upper_disc_size_mm` 独立配置，省略时保留旧比例。圆盘包络、支杆与剪叉均为简化展示，不解真实机构。探测器有效像素面固定在 D 的 `z=0`，与外壳分开处理。

默认层级配色为浅黄方柱、亮银六轴、中灰转接板、炭黑 Z、深浅青绿 XYθ 和棕色样品；颜色值以配置及渲染源码为准。选中边线保留主体颜色，XY 子实体拾取归入 θ 宿主。拾取不穿透遮挡，拖动/缩放不应误作选择。

“坐标与方向”的四个预设与保存的 display 开关共同决定可见内容：默认只看晶体坐标；晶格方向单独查看；装置坐标显示当前对象与实验室；全部对照用于工程核对。保存图层关闭时给出设置入口，不能为了展示预设而悄悄改写 snapshot。

晶体坐标用实线，晶格方向用虚线，目标用品红；箭头长度仅用于显示，不代表晶格常数。只有真实点和 frame 原点参与重合位置分组，任意绘图长度的箭头尖端即使同位置也不合并。标签保留上一帧仍合法的相对位置以减少闪动，越界或碰撞时重新避让；偏移只在显示层。场景外的锚点不贴边冒充可见点。

中文字体由 CSS 显式指定 Microsoft YaHei / Noto Sans CJK SC；检查导出的截图时同时核对中文、负号和数学符号。

## 验证和发布入口

需要 Node.js 24 或更高版本；依赖版本由 [package-lock.json](../package-lock.json) 固定。常用命令：

```sh
npm test -- --run
npm run typecheck
npm run build
npm run test:e2e
npm run preview
```

[核心测试](../tests/core.test.ts)用独立数值例子核对运动学与晶体学；[展示测试](../tests/labels.test.ts)核对实际矩阵、几何接触、图层和标注；[浏览器流程](../tests/browser/workflows.spec.ts)核对编辑、保存恢复、选中、标签和窄屏。具体运行结果、人工拾取覆盖和接受边界只引用 Spec，不复制测试计数、耗时、截图清单或逐轮 review 日志。

E2E 当前使用 Edge 的 `msedge` channel / SwiftShader，并自行启停 `127.0.0.1:4173`；不要复用或停止用户的 5173 评审服务。其他系统需选择可用浏览器。如果进程代理为 `socks5:`，仅为测试进程追加 loopback `NO_PROXY`。Windows 沙箱中浏览器子进程可能受限，历史验证使用正常 Windows 用户边界；不据沙箱失败判定产品故障。

开发默认根路径。[Pages 工作流](../.github/workflows/pages.yml)通过 `PAGES_BASE_PATH` 设置仓库子路径，执行依赖安装、测试和构建，只上传 `dist`；部署使用 Pages/OIDC 权限，无需把个人 token 写进仓库。`npm run preview`用于本地检查构建，不是生产服务器。发布路径变更须核对实际资源加载与 WebGL 交互，不能只看 HTTP 200。

工程验证不等于实物标定、控制器 UVW 映射或硬件行程认证。本工具没有真实设备控制、完整机械 CAD、机构反解或碰撞安全判断；后续范围由 Spec 持有。Vite 的包体积提示仍保留，尚未实现按需拆包。

可再生截图与运行产物放在 ignored `artifacts/`；源码和文档版本从 Git 查找，不复制项目留版。新增维护结论应更新本文件的对应主题；需求、任务及验收状态更新 Spec，尺寸来源更正更新尺寸记录。
