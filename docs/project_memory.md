## 坐标和状态约定

- LAB 为右手系，`+Y` 向上、`+Z` 为入射方向；设备长度用 mm，角度界面用°（配置/API仍用deg），晶格长度用 Å，方向输出为无量纲单位向量。
- 变换使用列向量，公开矩阵数组按行存储。完整数学定义与接口合同见 Spec，不以 Three.js 对象位置作为物理真值。
- 默认链为 `LAB → R → H0 → H1 → Z0 → Z1 → P0 → P1(θ) → P2(XY) → S → C`；探测器支撑架独立属于 LAB，平板固定安装在架上；光束独立定义在 LAB。晶体 C 是正交坐标系，晶格基矢一般不正交。
- 六轴安装零位、关节平移/倾转和旋转参考点分别定义。内部 H0/H1 与厂图原点不能直接等同；参考面区别见尺寸记录，不据图纸标记推断控制器坐标或真实 pivot。
- `direct` 表示晶向，`reciprocal` 表示晶面法向；切换类型是重新解释指标，不是二者之间的换算。

## 编辑与兼容性

Scene 是唯一物理状态来源。编辑先构造候选 snapshot，再通过 `restore_state()` 校验并原子应用；失败不改变已有状态。输入结构由 Schema 约束，跨引用、层级和角色关系由加载器校验。

安装位置与内部运动分开处理：修改安装位置平移对应分支，保持内部关节读数；外层旋转轴中心与零位 mount 同步移动。默认大样品台的“台面升高”和安装 Y 共用更新路径，联动安装、轴心及柱体外观以保持柱底；“柱体外观高度”只改变外形并保持柱顶，不是升降运动。

XY 一体关系由 `integrated_into` 声明。加载器检查 XY 零行程基座位于 θ 轴中心，不把运动后的 XY 原点误当固定基座；未声明一体关系的旧配置仍按独立装配处理。直接绑定 LAB 或派生晶体坐标系的对象没有独立 mount，参数区保留只读绑定信息。

样品“观察方向”与“晶体取向”分别提交，各自从当前 Scene 保留另一组已应用值，不读取另一组未应用草稿。取向用单位四元数表示旋转 `R_SC`，修改它不移动样品机械位置。普通文件载入读取独立的文件内容缓存；高级 JSON 编辑读取自身草稿，不能互相替代来源。

snapshot 保存设备、装配、关节、样品和原有三个 display 开关。相机、当前选择、诊断总开关和查看预设只影响画面，不写入 snapshot。

根级可选 `diffraction` 保存预览的活动对象和计算参数。缺项旧配置原样加载/导出；唯一样品和探测器可以临时使用默认值，非立方默认 primitive，多候选需明确选择。显式配置的坏 ID/不兼容 FCC 会被拒绝；修改参数使用同一原子 restore。预览开合和斑点选择不保存。`compare_states` 的 `diffraction_changed` 单独报告其变化，且计入 `configuration_changed`。

预览主区的晶格常数a直接读写活动sample的`crystal.cell`，不在diffraction另存副本。立方下联动a=b=c，非立方仅更新a、保留b/c及角度；参考d由同一cell重算。编辑失焦或Enter提交，非法值恢复有效值。修改a、选择查看晶面、复位、采用四月参照和载入配置都必须同步这些控件与预测结果；不得把a与某个(hkl)的d互相标错。

现有圆斑以固定浅灰色和原始几何权重控制不透明度，黑底上越亮表示响应越强；HKL使用深底浅字，选中提示独立粉色描边，不修改信号本体。仍使用SVG圆斑，不透明度重叠不是探测器线性强度累加。高斯核/真实强度的未来范围由[#3](https://github.com/David-JA/lab-frame-experimental-geometry/issues/3)持有，未实现。

衍射核心用 `1/λ`、Å⁻¹，不含 `2π`。发射重心由机械 S 系的有限照明体积分得到，R_SC 只转晶格；照明模型尺寸与放大的视觉外形分开。直射参考始终投影固定光束中心线。预览和三维共用 D frame；四月 PONI/work/raw 转换仅在预设适配时做一次。默认实验室场景采用四月参照，旧合成场景保持原几何。面板运动中每秒采样最新姿态，暂停/限位后立即补最终结果，手动编辑/重新展开立即更新，相同revision不重算；关闭取消任务。调度复用单轴控制器的显式运行状态通知，不按静止防抖；晶格候选与机械照明分别缓存。1s采样不代表曝光积分，可能错过短暂反射。

连续运动在当前装置的运动区统一选轴，位移速度mm/s、旋转°/s，位置以cm显示时也按mm/s换算。全局只运行一轴，每帧复用Scene更新；到已配置端点停止。切换装置/轴、修改速度/参数、打开配置、后台或离页时暂停，恢复后需显式开始。轴选择、速度与运行状态仅为UI状态，不随snapshot保存；不驱动真实硬件。

连续运动的启动与逐帧增量使用同一单调时钟，不混用rAF缓存帧时间；离页进入浏览器缓存时只暂停，真正销毁时才移除监听器和释放viewer，避免返回后失去后台暂停处理。

运动区标题右侧统一称“复位”：先暂停，再用一个候选snapshot一次性复位当前装置全部运动轴；XYθ同时处理θ/X/Y。常规轴回零，行程不含零的轴回到允许范围内最接近零的位置，默认Z为100 mm（界面10 cm）。不改其他装置读数、安装或pivot；台面升高复位仍通过既有高度联动保持柱底。

## 外观与观察层

`visual.size_mm`、`visual.offset_mm` 只改变外观，不缩放物理 frame。六轴上下复合件分别附着 H1/H0；上盘可用 `upper_disc_size_mm` 独立配置，省略时保留旧比例。大样品台方柱底部显示20 mm厚金属灰圆盘，直径取方形底面对角线；圆盘占用原外观包络的底部20 mm，方柱相应缩短，整体底面、顶面、安装frame与台面高度不变；外观总高小于20 mm时按总高显示圆盘。圆盘包络、支杆与剪叉均为简化展示，不解真实机构。探测器有效像素面固定在 D 的 `z=0`，与外壳分开处理。

默认层级配色为浅黄方柱、亮银六轴、中灰转接板、炭黑 Z、深浅青绿 XYθ 和棕色样品；颜色值以配置及渲染源码为准。选中边线保留主体颜色，XY 子实体拾取归入 θ 宿主。拾取不穿透遮挡，拖动/缩放不应误作选择。

鼠标左键拖动旋转，中键按住拖动平移，滚轮缩放；右键不绑定相机动作，避免与浏览器手势竞争。中键不再采用OrbitControls默认的拖动缩放，平移沿用正常速度。

“坐标与方向”的四个预设与保存的 display 开关共同决定可见内容：默认只看晶体坐标；晶格方向单独查看；装置坐标显示当前对象与实验室；全部对照用于工程核对。保存图层关闭时给出设置入口，不能为了展示预设而悄悄改写 snapshot。

晶体坐标用实线，晶格方向用虚线，目标用品红；箭头长度仅用于显示，不代表晶格常数。只有真实点和 frame 原点参与重合位置分组，任意绘图长度的箭头尖端即使同位置也不合并。标签保留上一帧仍合法的相对位置以减少闪动，场景revision重建也按稳定的角色/成员身份承接，不以移动中的坐标或临时Three对象识别。共点拆合或身份重复时重新布局，越界或碰撞时仍重新避让；偏移只在显示层。场景外的锚点不贴边冒充可见点。

中文字体由 CSS 显式指定 Microsoft YaHei / Noto Sans CJK SC；检查导出的截图时同时核对中文、负号和数学符号。

倒易斑点直径默认0.1 Å⁻¹，是便于观察的演示值，未由实测峰宽标定。它同时影响反射出现的角度范围、几何权重和圆斑大小，不是单纯放大屏幕标记。载入配置及应用四月参照继续保留用户显式设置。

衍射参数中，能量、样品尺寸及光束尺寸的原生增减箭头按当前值增减1个对应单位，手动输入仍支持小数，不预先截断标定值。采用`step="any"`避免浏览器按微小min对齐而产生2.0001等尾数。晶格常数a保留0.0001 Å步长；倒易直径步长0.01 Å⁻¹，步进基准为0，严格正值约束仍由提交验证持有。左侧装置参数原已采用`step="any"`，无需重复修改。

晶面间距d是当前cell与所选hkl的只读计算值，独立卡片展示，不再提供输入d反向修改a的入口；切换hkl只更新该读数，不筛选反射或改变配置。旧界面中只输入d并不生效，需另点应用，现已移除这条易混淆路径。衍射标题旁“复位”保留当前有效样品/探测器选择、全部装置运动、安装与晶体取向；恢复默认预览设置及所选样品的立方晶格，并把查看晶面恢复111；保留平板标定、像素配置及支撑架位置。它与保留显式点径等选择的“采用四月参照参数”语义不同。

同一卡片显示理论散射角`2θ=2 asin(λ/(2d))`（°，`λ=HC_KEV_A/E`，布拉格角为θ）与散射矢量大小`q=2π/d`（Å⁻¹）。这是含2π的常用散射矢量口径，与内部倒易球的1/d口径明确区分；未更改内部模型。能量变化只改变2θ，不改变d/q；λ>2d时2θ显示“—”并解释当前能量不可达，d/q仍显示。无活动对象或非法hkl时三行均清空，不能沿用旧值。理论角不表示当前取向已激发、反射允许或落在探测器内。

“参照参数与示例”中的低阶骨架表随当前FCC立方晶格a、能量及探测器pose更新。参考100带轴含4个{200}+4个{220}，110含4个{111}+2个{200}+2个{220}，均固定[001]向上、样品在光束参考点居中；是独立参考摆放，不修改或声称复现当前机械姿态。零阶层g_parallel=0时球形倒易点临界直径`Dcrit=2g²/(sqrt(k²+g²)+k)`，k=1/λ，需D>Dcrit才有正响应；与探测器距离无关。面板覆盖复用当前D平面投射各中心射线，单独计数，不能用增大D解决中心出界。默认a=3.59033485 Å、λ=.1265 Å时，111/200/220临界直径约.029413/.039205/.078313 Å⁻¹；两套完整8点均由220限制。距离变化只改变覆盖和图样尺寸；对这里的严格带轴参考，提高E降低阈值，约按1/E缩小；一般固定姿态下的反射响应不保证随E单调增加。

## 探测器双轴定位与标定安装

当前默认装配为 `LAB → D_support → D`。`detector_support` 必须是 LAB 的直接固定子坐标系，轴向与 LAB 对齐；X/Z 是左侧“固定位置”中的绝对 LAB 坐标（mm），Y 为固定安装高度，不新增电机关节或速度控制。支架外形仅为示意，双轴轨道不绘制。连接块与立柱按平板外壳在支架坐标系中的完整包络放到后方，包含标定倾斜、安装偏移及固定转接件，并留2 mm显示间隙；只调整渲染外形，不改平板物理frame或PONI。

平板相对支撑架的位置与四元数保存标定安装，左侧只读；若有固定转接件，读数取支撑架到平板的完整合成变换。换距与横移只改支撑架 X/Z，保留平板的架内偏移、倾角、像素参数、样品位置与运动读数。PONI 法向距离独立计算为 `d = (C − B)·n`，其中 C 是平板中心、B 是配置光束参考点、n 是平板有向单位法线；它不是样品偏心后的光程。固定标定下 `Δd = n_x ΔX + n_z ΔZ`，因此倾斜面板的轨道位移通常不等于法向距离变化。

旧配置加载/导出不自动改变结构，平板安装同样只读。高级区“按当前安装建立支撑架”显式升级，保持平板世界位姿；若原 frame 是 LAB、与其他装置共享或带子坐标系，则为选中平板建立专属分支，其他对象保留。已升级配置直接保存/恢复双轴位置与架内标定。

“复位”只恢复预览参数与默认晶格，不移动支撑架或重写平板标定。“采用四月参照参数”是显式标定操作：更新平板相对架的四月安装与像素参数，保留已有支撑架位置；首次创建支架时恢复原四月世界位姿。单块平板重新标定时，若原安装 frame 共用或带其他子挂载，则先为目标平板分离专属固定 frame，其他挂载保持原位。两者均保留装置运动与晶体取向。

## 验证和发布入口

衍射面板的公式、数学符号和单位使用在线KaTeX 0.19.1排版，从jsDelivr按需加载固定版本ES模块、CSS及字体；运行包不包含KaTeX或字体文件。`katex`仅作为开发依赖提供类型和公式核对。只渲染代码明确标记的公式节点，保留HTML+MathML，输入框及计算用数值不改写；中文继续使用原中文字体。更新CDN版本时同步开发依赖和真实网络浏览器核查。

需要 Node.js 24 或更高版本；依赖版本由 [package-lock.json](../package-lock.json) 固定。常用命令：

```sh
npm test -- --run
npm run typecheck
npm run build
npm run test:e2e
npm run preview
```

[核心测试](../tests/core.test.ts)用独立数值例子核对运动学与晶体学；[展示测试](../tests/labels.test.ts)核对实际矩阵、几何接触、图层和标注；[运动时钟测试](../tests/motion.test.ts)核对速度积分、单轴互斥、限位和暂停；[衍射数值测试](../tests/diffraction.test.ts)核对激发、独立PONI和照明体对照；[预览调度测试](../tests/preview-refresh.test.ts)核对持续变动时采样和暂停/关闭行为；[工作台浏览器流程](../tests/browser/workflows.spec.ts)与[衍射浏览器流程](../tests/browser/diffraction.spec.ts)核对实际交互和窄屏。具体运行结果、人工拾取覆盖和接受边界只引用Spec，不复制测试计数、耗时、截图清单或逐轮review日志。公开Issue #3的[模型策略追加说明](https://github.com/David-JA/lab-frame-experimental-geometry/issues/3#issuecomment-6794866278)解释当前有限倒易球、权重与显示亮度的计算口径；仍是后续强度扩展的讨论入口。

E2E 当前使用 Edge 的 `msedge` channel / SwiftShader，并自行启停 `127.0.0.1:4173`；不要复用或停止用户的 5173 评审服务。其他系统需选择可用浏览器。如果进程代理为 `socks5:`，仅为测试进程追加 loopback `NO_PROXY`。Windows 沙箱中浏览器子进程可能受限，历史验证使用正常 Windows 用户边界；不据沙箱失败判定产品故障。

开发默认根路径。[Pages 工作流](../.github/workflows/pages.yml)通过 `PAGES_BASE_PATH` 设置仓库子路径，执行依赖安装、测试和构建，只上传 `dist`；部署使用 Pages/OIDC 权限，无需把个人 token 写进仓库。`npm run preview`用于本地检查构建，不是生产服务器。发布路径变更须核对实际资源加载与 WebGL 交互，不能只看 HTTP 200。

工程验证不等于实物标定、控制器 UVW 映射或硬件行程认证。本工具没有真实设备控制、完整机械 CAD、机构反解或碰撞安全判断；后续范围由 Spec 持有。Vite 的包体积提示仍保留，尚未实现按需拆包。

可再生截图与运行产物放在 ignored `artifacts/`；源码和文档版本从 Git 查找，不复制项目留版。新增维护结论应更新本文件的对应主题；需求、任务及验收状态更新 Spec，尺寸来源更正更新尺寸记录。
